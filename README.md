# Clean-Financy


## Problema
Clean Financy visa solucionar o problema de pequenos comércios que não conseguem organizar suas finanças, entradas e saídas de produtos. 

## Público
Pequenos negócios, comerciantes e micro-empresas

## Solução

a clean financy usará um metodo tecnologico e atualizado para facilitar e automatizar seu negocio, por meio de um sistema prático e eficiente de ser utilizado.

## Objetivo da Sprint

Nosso primeiro objetivo consiste em entender e estudar como funciona as entradas e saídas de um comércio juntamente com um sistema base para testes
